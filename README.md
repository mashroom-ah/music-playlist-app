# 🎵 Список любимых песен

React-приложение для управления плейлистом любимых музыкальных треков.

## 🚀 Функционал

- ✅ Добавление новых песен с обложками
- ✅ Удаление песен
- ✅ Отметка песен как избранных
- ✅ Фильтрация по избранным песням
- ✅ Сохранение данных в LocalStorage
- ✅ Адаптивный дизайн

## 🛠 Технологии

- React 18
- CSS3 (Flexbox, Grid)
- LocalStorage API
- Vite
